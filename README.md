# [開啟 FIRE 計算機](https://tyson3822.github.io/fire-calculator/)

FIRE 計算機是一個單頁版的財務自由試算工具，用來估算長期投資、工作收入、退休提領、購屋與房貸對現金流及資產的影響。

## 功能

- 全域時間軸、年齡與資產初始設定
- 經常月薪、年度獎金、薪資成長與退休提領
- 投資年利率換算月利率的逐月複利，收益直接納入投資資產
- 獨立的投入投資試算組，可從指定年月切換百分比、固定金額、支出餘額、備用金或定期定額策略
- 直接購入與預售屋房貸試算
- 分段房貸利率
- 購屋額外支出，例如裝潢、設計與家具
- 年度表格、逐月資產明細視窗、互動圖表與公式明細
- JSON 設定匯入／匯出與 CSV 結果輸出
- 使用說明導覽與預設情境導覽

## 注意事項

試算中的現金資產與投資資產分開計算。現金資產出現負數時，代表當年度現金流需要透過投資資產變現或其他資金調度補足，不代表投資資產已經歸零。

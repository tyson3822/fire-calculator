FIRE 計算機

加入全域時間軸：指定開始年份、試算年數與出生年。每個試算組再指定「插入年份」，只有進入該年份後才開始作用；表格與圖表同步顯示年份與試算人年齡。
設定檔格式：JSON
時間軸 / 初始設定
現金資產與投資資產都從試算第一年開始存在，並逐年累積。所有支出只從現金資產扣除，不會自動賣出投資資產補足。
動態固定支出表
每一列代表「從該年份開始」使用新的固定年支出；年份必須嚴格遞增。最後一個階段會一直沿用到試算結束。
緊急備用金目標表
每一列代表「從該年份開始」希望保留的現金資產目標。若投入方式選「僅保留緊急備用金」，當年度所有收入、固定支出、購屋與房貸都結算後，超過此目標的現金才轉入投資。最後一階段永久沿用。
經常收入試算組
「支出餘額」會使用上方動態固定支出表中該年度的支出額：投入投資 = max(0, 工作收入 − 當年固定支出)。
先結算當年所有現金流，再把超過當年「緊急備用金目標」的現金全部轉入投資。
「支出餘額」同樣使用動態固定支出表：退休再投入 = max(0, 退休提領收入 − 當年固定支出)。
退休提領先進入現金，扣除固定支出與房貸後，只保留當年緊急備用金目標，其餘再投入投資。
複利計算試算組
複利再投入階段
每個階段代表「從開始年份起，連續若干年將投資收益再投入」。不在任何複利階段內的年份，投資收益會納入現金資產。階段不可重疊。
投資資產與年化報酬率由「時間軸 / 初始設定」提供；這裡只決定哪些年份要把投資收益再投入投資資產。
房貸試算組
房貸利率階段
可模擬購屋補助、銀行優惠期或分段式房貸。每個階段依序接續；最後一階段的持續年數設為 0 代表一路套用到房貸結束。利率切換時會依當下剩餘本金與剩餘期限重新計算月付。
房貸、頭期款與工程款均為現金支出；不足時現金餘額會呈負值，不會自動賣投資資產補洞。

年度計算公式 / 驗收區

以下就是頁面實際採用的計算順序；最下方可指定年度查看數值代入。
① 投資複利投資收益[t] = 年初投資資產[t] × 年化報酬率 位於複利再投入階段：投資收益總額 → 投資資產再投入 不在複利再投入階段：投資收益總額 → 現金資產
② 工作收入投入百分比：投入 = 工作收入 × % 固定：投入 = min(工作收入, 固定金額) 支出餘額：投入 = max(0, 工作收入 − 當年固定支出) 工作收入未投入部分會留在現金資產。
③ 退休提領提領前資產 = 年初投資資產 + 投資收益再投入 退休提領收入 = 提領前資產 × 提領率 退休再投入 = allocation(退休提領收入) 退休現金 = 退休提領 − 再投入
④ 所有支出只扣現金年度淨現金流 = 工作收入 − 工作投入 + 退休提領 − 退休再投入 − 固定年支出 − 頭期 / 工程 / 房貸支出 年末現金資產 = 年初現金資產 + 年度淨現金流
⑤ 投資資產逐年累積一般模式： 年末投資 = 年初投資 + 收益 + 工作投入 − 退休提領 + 退休再投入 僅保留緊急備用金： 先完成所有年度現金流， 超額現金 = max(0, 結算後現金 − 當年備用金目標) 再把超額現金轉入投資。 任何支出都不直接扣投資資產。
⑥ 全域時間軸年份[t] = 開始試算年份 + t 年齡[t] = 年份[t] − 出生年 總列數 = 全域試算年數 各試算組只有在「插入年份」後才生效。

FIRE 計算機

加入全域時間軸：指定開始年份、試算年數與出生年。每個試算組再指定「插入年份」，只有進入該年份後才開始作用；表格與圖表同步顯示年份與試算人年齡。
設定檔：JSON · 結果表：CSV
時間軸 / 初始設定
投資收益每月以「月初投資資產 × 年利率 ÷ 12」計算並直接納入投資資產；月底投入會從下一個月開始參與複利。所有支出只從現金資產扣除，不會自動賣出投資資產補足。
動態固定支出表
每一列代表「從該年份開始」使用新的固定年支出；年份必須嚴格遞增。最後一個階段會一直沿用到試算結束。
緊急備用金目標表
每一列代表「從該年份開始」希望保留的現金資產目標。若投入方式選「僅保留緊急備用金」或「保留緊急備用金後定期定額」，每月底完成收入、固定支出、購屋與房貸結算後，才會將超過目標的現金轉入投資。最後一階段永久沿用。
經常收入試算組
「支出餘額」按月計算：投入投資 = max(0, 當月工作收入 − 當月固定支出)。
每月底完成收入、固定支出與房貸結算後，把超過當年緊急備用金目標的現金全部轉入投資。
工作期間每月定期定額階段
每月底先保留當年緊急備用金，再投入 min（超額現金，當年每月定期定額）。最後一個階段會持續沿用。
「支出餘額」按月計算：退休再投入 = max(0, 當月退休提領 − 當月固定支出)。
每月退休提領進入現金並扣除支出與房貸後，只保留當年緊急備用金目標，其餘再投入投資。
退休期間每月定期定額階段
每月底先保留緊急備用金，再依當年設定的每月金額定期投入。
房貸試算組
直接購入會在購入年列入；預售屋會在工程期結束、交屋年列入。
房貸利率階段
可模擬購屋補助、銀行優惠期或分段式房貸。每個階段依序接續；最後一階段的持續年數設為 0 代表一路套用到房貸結束。利率切換時會依當下剩餘本金與剩餘期限重新計算月付。
房貸、頭期款與工程款均為現金支出；不足時現金餘額會呈負值，不會自動賣投資資產補洞。

每月計算公式 / 年度驗收區

模型逐月計算並彙整成年表；最下方可指定年度查看數值代入。
① 每月投資複利月利率 = 投資年利率 ÷ 12 當月收益 = 月初投資資產 × 月利率 收益直接加入投資資產；月底投入從下個月起參與複利。
② 工作收入與投入每月底入帳經常月薪；獎金依 1／2／4 次設定於指定月份月底入帳。 百分比：投入 = 當月工作收入 × % 固定：投入 = min(當月工作收入, 每月固定金額) 支出餘額：投入 = max(0, 當月工作收入 − 當月固定支出) 工作收入未投入部分會留在現金資產。
③ 退休提領當月提領前資產 = 月初投資資產 + 當月收益 當月退休提領 = 提領前資產 × 年提領率 ÷ 12 退休再投入 = allocation(退休提領收入) 退休現金 = 退休提領 − 再投入
④ 所有支出只扣現金年度淨現金流 = 工作收入 − 工作投入 + 退休提領 − 退休再投入 − 固定年支出 − 頭期 / 工程 / 房貸支出 年末現金資產 = 年初現金資產 + 年度淨現金流
⑤ 投資資產逐月累積月底投資 = 月初投資 + 當月收益 + 工作投入 − 退休提領 + 退休再投入 僅保留緊急備用金： 先完成所有當月現金流， 超額現金 = max(0, 月底現金 − 當年備用金目標) 再把超額現金轉入投資。 保留備用金後定期定額： 投入 = min(超額現金, 當年每月定期定額)。 任何支出都不直接扣投資資產。
⑥ 全域時間軸年份[t] = 開始試算年份 + t 年齡[t] = 年份[t] − 出生年 總列數 = 全域試算年數 各試算組只有在「插入年份」後才生效。
⑦ 月配額與風險健康度月平均配額 = 全試算期間固定支出總額 ÷（試算年數 × 12） 當年年末現金資產 < 0 且 當年年度淨現金流 < 0：有風險 其餘情況：無風險 整段試算只要任一年符合上述雙重負值條件，即判定為有風險。 風險年份 = 首次同時出現雙重負值的年份。
